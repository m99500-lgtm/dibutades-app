# 디부타데스 (Pi Dibutades)

> "느낌 오면 낙서하면 돼~" / "Feel something? Just scribble it." 🍀

사람이 직접 쓴 한 줄을 소중히 모으는 Pi Network 커뮤니티 앱입니다.
낙서를 남기고, 함께 그림을 그리고, 오늘의 소식과 사기 경보를 나누는 작은 광장입니다.

- **배포 주소:** https://dibutades-app.vercel.app (Pi Developer Portal에 등록된 Mainnet URL)
- **만든 사람:** 로저 (X @minkyeungsoon31)

## 1. 화면 구성

맨 위에 고정된 탭 4개로 이동합니다: **쓰기 · 낙서벽 · 갤러리 · 007 경보**

| 탭 | 하는 일 |
|---|---|
| ✏️ 쓰기 (Write) | 매일 바뀌는 질문에 답하며 짧은 낙서를 남깁니다. Pi 로그인 필요, 붙여넣기·드래그 입력 차단. 연속 작성일(스트릭)이 표시됩니다. |
| 🧱 낙서벽 (Wall) | 모두의 낙서를 조용히 둘러봅니다. 하트·엄지척·기도·기쁨·슬픔 중 하나로 반응을 남길 수 있습니다. |
| 🖼️ 갤러리 (Gallery) | 로흐(로저)의 디지털 아트 연작, 함께 그리는 **파이오니어들의 은하**, 완성된 은하 작품들이 걸려 있습니다. |
| 🛡️ 007 경보 (Scam Alert) | 파이 관련 사기성 앱·이벤트·패스프레이즈 유도 사례를 위험/주의/참고 단계로 알립니다. 글은 관리자만 올립니다. |

**쓰기 화면 아래에 이어지는 것들**
- **오늘의 소식** — 4개 색 탭
  - Pi 소식 · 코인 소식 (최근 며칠 안의 뉴스만, 15분마다 갱신)
  - 역사 속 오늘 — "이날의 한 줄 남기기"로 바로 쓰기
  - 오늘 뭐 먹지? — 세계 지도 위에 나라별 한 끼를 올리고, "이 음식 먹어봤어요?" 한 줄 남기기 (한 사람 하루 3번, 3일간 보관)
- **오늘 띠** — 오늘 낙서 수 · 방문 수 · π 가격
- **맨 아래 링크** — 앱 홍보 화면 열기

**헤더**: 디부타데스 로고 + soSOso 애니메이션 + 라이트/다크 전환(🌙), 그 아래 외계 시각 연작 띠(누르면 갤러리로)

## 2. 파이오니어들의 은하 (함께 그리는 작품)

- 직접 그리는 버튼은 없습니다. Pi Browser에서 로그인한 파이오니어가 앱 안의 **어떤 버튼이든 누르면**, 우주 어딘가에 무작위 획(호·나선·물결·고리)이 하나씩 자동으로 그려집니다.
- 한 사람당 15초 간격, 하루 40획까지. 한 작품에 최대 6,000획이며, 넘치면 가장 오래된 자동 획부터 사라집니다.
- 작품은 **제1호, 제2호…** 처럼 호수로 이어집니다. 관리자가 "완성하기"를 누르면 제목을 붙여 갤러리의 "완성된 은하"에 걸리고, 다음 호가 새로 시작됩니다.
- 완성작은 `cosmos.html?ed=번호` 주소로 볼 수 있습니다.

## 3. 앱 홍보 (개발자용)

Pi 생태계 앱 개발자가 자기 앱을 디부타데스에 소개할 수 있습니다.

| 요금제 | 노출 기간 |
|---|---|
| 0.5 Pi | 7일 |
| 1.5 Pi | 30일 |
| 무료 홍보권 | 1일 (7일 연속 낙서할 때마다 1장) |

- 결제는 Pi 공식 결제(U2A)로만 처리됩니다.
- 홍보 링크는 `pi://` 또는 `*.pinet.com` 주소만 허용됩니다 (화면 + 서버 이중 검사).

## 4. 코어팀 정책을 지키도록 만든 부분

| 정책 | 이 앱에서의 반영 |
|---|---|
| 외부 사이트로의 리다이렉트 제한 | 홍보 링크는 Pi 생태계 주소만 허용 |
| 불필요한 개인정보 수집 금지 | 이메일·전화번호·위치 수집 안 함. Pi 사용자명과 본인이 쓴 글만 저장 |
| 앱이 완전히 작동해야 함 | 모든 탭이 실제로 동작 |
| 투자 권유·과장 홍보 없음 | 보상이나 수익을 약속하는 기능·문구를 두지 않음 |

> 정책은 바뀔 수 있으니, 심사 신청 전에는 Pi Developer Portal의 최신 안내를 다시 확인하세요.

**로그인 안내**: Pi 로그인은 Pi Browser 안에서만 자동으로 시도합니다. X·네이버 같은 앱 안 브라우저로 들어오면, 파이오니어에게는 "Pi Browser에서 열기"(주소 복사 버튼), 파이오니어가 아닌 분께는 둘러보기 안내가 먼저 나옵니다.

## 6. 데이터 저장 (Vercel Blob, Private)

| 파일 | 내용 |
|---|---|
| `dibutades-data.json` | 낙서, 반응, 홍보, 스트릭, 무료 홍보권 |
| `dibutades-visits.json` | 날짜별 방문 수 |
| `dibutades-cosmos.json` | 지금 그려지는 은하 |
| `dibutades-cosmos-ed-N.json` | 완성된 은하 제N호 |
| `dibutades-cosmos-editions.json` | 완성된 은하 목록 |
| `dibutades-meals.json` | 오늘 뭐 먹지? 한 끼 기록 |

알려진 한계: 파일 하나를 통째로 읽고-고쳐서-다시 쓰는 방식이라, 아주 짧은 순간에 두 사람이 동시에 저장하면 한쪽이 덮일 수 있습니다. 사람이 많아지면 실제 데이터베이스로 옮기는 걸 고려하세요.

## 7. 환경변수 (Vercel → Settings → Environment Variables)

| 이름 | 용도 |
|---|---|
| `PI_API_KEY` | Pi 서버 API 키 (결제 승인·완료, 로그인 확인) |
| `BLOB_READ_WRITE_TOKEN` | Blob 저장소 연결 시 자동 생성 |
| `COSMOS_ADMIN` | (선택) 은하 완성·007 경보 관리자 Pi 사용자명. 비우면 기본 관리자 사용 |

## 8. 배포

GitHub 저장소 `m99500-lgtm/dibutades-app`의 `main` 브랜치에 파일을 올리면 Vercel이 자동으로 다시 배포합니다.

로컬에서 실행해 보려면:
```
npm install
PI_API_KEY=발급받은키 npm start
```
그다음 http://localhost:3000 에 접속합니다. 로그인·결제는 Pi Browser 안에서만 동작합니다.
