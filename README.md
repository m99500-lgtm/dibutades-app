## 2. 쓰기 화면

### 오늘의 투표
- 요일마다 주제가 바뀌는 질문 묶음(7개 주제 × 9개 투표)에서 하루 하나가 나옵니다. 파이데이(3.14)·2π데이(6.28) 같은 특별한 날에는 특별 투표가 나옵니다.
- 보기마다 "✏️ 다른 생각"이 자동으로 붙고, 누르면 아래 쓰기 칸에 `#오늘의투표`가 채워져 직접 한마디를 남길 수 있습니다.
- 투표하면 결과 막대가 보이고, **막대를 누르면 나라별 투표 수**가 펼쳐집니다. (나라 단위 합계만 저장, 개인 위치는 저장하지 않음)
- **관리자 특별 투표**: 관리자 계정으로 로그인하면 "오늘의 투표 바꾸기" 버튼이 보입니다. 한국어로 질문과 보기를 쓰면 영어 칸이 자동 번역되고, 두 번 확인한 뒤 그날의 투표가 바뀝니다. 다른 유저에게는 이 버튼이 보이지 않습니다.

### 오늘의 007 퀴즈
- "이건 사기일까?" 하루 한 문제 (로그인 없이 누구나). 60개 문제가 날짜에 맞춰 차례로 돌아갑니다.

### 낙서 쓰기
- Pi 로그인 필요. 붙여넣기·끌어다 놓기는 막혀 있어 직접 쓴 글만 올라갑니다.
- 연속 작성일(스트릭)이 표시되고, 7일 연속마다 무료 홍보권 1장을 받습니다.
- 버튼과 안내 문구는 한국어·영어가 함께 표시됩니다.

### 오늘의 소식
- 4개 탭 버튼만 보이고, 누를 때 내용이 펼쳐집니다 (같은 탭을 다시 누르면 닫힘). 화면이 길어지지 않게 하기 위함입니다.
  - **Pi 소식 · 코인 소식**: 최근 며칠 안의 뉴스만, 한국어 → 영어 순서로 표시 (15분마다 갱신)
  - **역사 속 오늘**: 한국어 위키백과 기준, 한국어와 영어 번역을 함께 표시 (하루 한 번 저장)
  - **오늘 뭐 먹지?**: 세계 지도 위에 나라별 한 끼를 올립니다 (한 사람 하루 3번, 3일간 보관)

### 맨 아래
- **오늘 띠**: 오늘 낙서 수 · 방문 수 · π 가격
- **링크**: 디부타데스 소개 · 당신의 Pi 앱 홍보하기

## 3. 007 게임 (보드게임 3종)

007 게임 탭에서 카드의 **입장** 버튼을 누르면 각 게임 화면으로 갑니다. 게임 화면 위의 **← 007 게임** 버튼으로 돌아옵니다 (`/#games`). 게임 안의 글은 전 세계 파이오니어를 위해 영어로 되어 있습니다. 모든 게임에서 007 요원 캐릭터가 칸을 따라 걸어갑니다.

| 게임 | 파일 | 방식 | 난이도 |
|---|---|---|---|
| 📜 파이 연대기 보드 (Pi Chronicle Board) | `game-chronicle.html` | 7×7 소용돌이 길(40칸)을 주사위 2개·5번의 기회로 걸어 파이의 역사를 지납니다. 39번 칸에 닿으면 가운데 **비밀의 방**이 열리고, 9개 파일 중 5개를 열어 사기·안전 판별 빙고를 합니다. 한 줄 완성마다 배지 1개. | ★☆☆ |
| 📅 랜덤 데이 루프 (Random Day Loop) | `game-loop.html` | 연말 SNS 트렌드 "A Random Day In…"을 담은 원형판. 주사위 2개를 굴려 **하나 또는 둘을 골라** 움직이고, 달 칸에서 타이밍을 맞춰 사진을 찍어 2026 회고 앨범에 스탬프를 모읍니다. 스탬프 3개마다 배지 1개. | ★★☆ |
| ⏳ 314 챌린지 (314 Challenge) | `game-314.html` | 모래시계 판(윗줄·아랫줄·두 대각선)을 8자로 한 바퀴 돌아, 멈춘 칸 숫자의 합을 **정확히 314**로 맞춥니다. 1~314 원형 룰렛(끝자리만큼 이동), 가운데 칸 숫자 3개 중 선택, ± 찬스카드 8장. 새 판마다 "신중하게 두면 70% 이상 314 가능"한지 스스로 검사합니다. 성공하면 배지 1개. | ★★★ |

**배지 원칙**
- 007 배지는 앱 안에서만 쓰는 기념품입니다. 돈 가치가 없고, 사고팔거나 교환할 수 없습니다. 토큰·코인 보상은 두지 않습니다.
- 지금은 각자의 기기(브라우저 저장소)에만 저장되고, 게임마다 하루 5개까지 받을 수 있습니다. 서버에는 게임 기록이 저장되지 않습니다.

## 4. 파이오니어들의 은하 (함께 그리는 작품)

- 직접 그리는 버튼은 없습니다. Pi Browser에서 로그인한 파이오니어가 앱 안의 **어떤 버튼이든 누르면**, 우주 어딘가에 무작위 획(호·나선·물결·고리)이 하나씩 자동으로 그려집니다.
- 한 사람당 15초 간격, 하루 40획까지. 한 작품에 최대 6,000획이며, 넘치면 가장 오래된 자동 획부터 사라집니다.
- 작품은 **제1호, 제2호…** 처럼 호수로 이어집니다. 관리자가 "완성하기"를 누르면 제목을 붙여 갤러리의 "완성된 은하"에 걸리고, 다음 호가 새로 시작됩니다.
- 완성작은 `cosmos.html?ed=번호` 주소로 볼 수 있습니다.

## 5. 앱 홍보 (개발자용)

Pi 생태계 앱 개발자가 자기 앱을 디부타데스에 소개할 수 있습니다.

| 요금제 | 노출 기간 |
|---|---|
| 0.5 Pi | 7일 |
| 1.5 Pi | 30일 |
| 무료 홍보권 | 1일 (7일 연속 낙서할 때마다 1장) |

- 결제는 Pi 공식 결제(U2A)로만 처리됩니다.
- 홍보 링크는 `pi://` 또는 `*.pinet.com` 주소만 허용됩니다 (화면 + 서버 이중 검사).

## 6. 코어팀 정책을 지키도록 만든 부분

| 정책 | 이 앱에서의 반영 |
|---|---|
| 외부 사이트로의 리다이렉트 제한 | 홍보 링크는 Pi 생태계 주소만 허용 |
| 불필요한 개인정보 수집 금지 | 이메일·전화번호·정확한 위치 수집 안 함. Pi 사용자명과 본인이 쓴 글만 저장. 투표는 나라 단위 합계만 저장 |
| 앱이 완전히 작동해야 함 | 모든 탭과 게임이 실제로 동작 |
| 투자 권유·과장 홍보 없음 | 보상이나 수익을 약속하는 기능·문구를 두지 않음. 게임 배지는 돈 가치 없는 기념품 |

> 정책은 바뀔 수 있으니, 심사 신청 전에는 Pi Developer Portal의 최신 안내를 다시 확인하세요.

**로그인 안내**: Pi 로그인은 Pi Browser 안에서만 자동으로 시도합니다. X·네이버 같은 앱 안 브라우저로 들어오면, 파이오니어에게는 "Pi Browser에서 열기"(주소 복사 버튼), 파이오니어가 아닌 분께는 둘러보기 안내가 먼저 나옵니다.

## 8. 데이터 저장 (Vercel Blob, Private)

| 파일 | 내용 |
|---|---|
| `dibutades-data.json` | 낙서, 반응, 홍보, 스트릭, 무료 홍보권 |
| `dibutades-visits.json` | 날짜별 방문 수 |
| `dibutades-poll.json` | 오늘의 투표 결과 (보기별 수, 나라별 합계) |
| `dibutades-poll-override.json` | 관리자가 정한 특별 투표 |
| `dibutades-quiz.json` | 오늘의 007 퀴즈 답 통계 |
| `dibutades-history.json` | 역사 속 오늘 (하루 한 번 저장) |
| `dibutades-meals.json` | 오늘 뭐 먹지? 한 끼 기록 |
| `dibutades-cosmos.json` | 지금 그려지는 은하 |
| `dibutades-cosmos-ed-N.json` | 완성된 은하 제N호 |
| `dibutades-cosmos-editions.json` | 완성된 은하 목록 |
| `dibutades-scam.json` | 예전 007 경보 글 (보관) |

**저장 횟수 아끼기**: Vercel Hobby 요금제의 Blob 쓰기 한도(월 2,000회)를 넘지 않도록, 방문 수·투표·퀴즈·은하 자동 획은 바로 저장하지 않고 서버 메모리에 모았다가 **5분마다 또는 30건마다 한 번에** 저장합니다. 저장 직전에 최신 파일을 다시 읽어 합치므로 기록이 사라지지 않습니다.

알려진 한계: 파일 하나를 통째로 읽고-고쳐서-다시 쓰는 방식이라, 아주 짧은 순간에 두 사람이 동시에 저장하면 한쪽이 덮일 수 있습니다. 사람이 많아지면 실제 데이터베이스로 옮기는 걸 고려하세요.

## 10. 배포

GitHub 저장소 `m99500-lgtm/dibutades-app`의 `main` 브랜치에 파일을 올리면 Vercel이 자동으로 다시 배포합니다.

- 루트 폴더: `server.js`, `news.js`, `cosmos.js`, `README.md`
- `public/` 폴더: 화면 파일(`index.html`, `game-*.html`, `gallery.html` 등)
- 웹에서 올릴 때 파일 이름 뒤에 `(1)`, `(9)` 같은 숫자가 붙지 않았는지 꼭 확인하세요. 이름이 달라지면 화면에 반영되지 않습니다.

로컬에서 실행해 보려면:
```
npm install
PI_API_KEY=발급받은키 npm start
```
그다음 http://localhost:3000 에 접속합니다. 로그인·결제는 Pi Browser 안에서만 동작합니다.

## 11. 알려진 이슈

- 일부 앱 안 브라우저에서 라이트/다크 전환 버튼이 동작하지 않는 경우가 있음 (PC 브라우저는 정상)
- 휴대폰 아래쪽 시스템 버튼과 겹치는 문제 때문에 탭을 화면 위쪽으로 옮김
- 게임 배지는 기기에만 저장되어, 브라우저 기록을 지우거나 기기를 바꾸면 처음부터 다시 시작됨
